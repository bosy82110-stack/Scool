# مِقياس — متابعة وصيانة التكييف

تطبيق عربي للفني لإدارة أجهزة التكييف في الفلل والمباني، وتسجيل القراءات الأسبوعية وسجل الصيانة وقطع الغيار والصور ومقارنة أداء الجهاز عبر الوقت.

## ما يقدمه الإصدار الحالي

- إدارة الفلل والمباني والغرف/الأجهزة وتسميات المواقع.
- بطاقة فنية لكل جهاز تشمل الشركة والنوع والموديل والسعة والفريون والرقم التسلسلي والقراءات الاسمية ودورية الصيانة.
- نموذج سريع لقراءات الأمبير وضغط السحب والطرد وحرارة الدخول والخروج، مع التاريخ والوقت والملاحظات.
- سجل مؤرخ للصيانة وقطع الغيار، مع معلومات القطعة القديمة والجديدة ورقمها.
- مقارنة اتجاه كل مؤشر لفترة 30 أو 90 أو 180 يومًا.
- تنبيه على الصيانة المستحقة وتغيرات القراءات الملحوظة.
- حفظ محلي على الجهاز باستخدام AsyncStorage؛ لا يتطلب حسابًا أو اتصالًا دائمًا.
- إرفاق صور من مكتبة الجهاز إلى ملف المعدات.

## التشغيل

```bash
pnpm install
pnpm dev
```

لفحص TypeScript والاختبارات:

```bash
pnpm check
pnpm test
```

## ملاحظات البيانات

تبدأ قاعدة التطبيق فارغة حتى لا تُخلط البيانات التجريبية بسجل الموقع الفعلي. تُحفظ المعلومات على الجهاز الذي أُدخلت منه، ولا تتم مزامنتها تلقائيًا إلى أجهزة أخرى أو إلى السحابة. تصنيف تغيّر القراءة تنبيه أولي للمراجعة الفنية، وليس تشخيصًا آليًا لعطل.

## بنية المشروع

- `app/(tabs)/index.tsx`: تدفق التطبيق المحلي وإدارة النماذج والتنقل.
- `features/hvac/`: أنواع البيانات والتخزين والتنبيهات والرسم والشاشات.
- `server/` و`drizzle/`: بنية القالب الحالية؛ لا يعتمد الإصدار الأول عليها لتخزين سجل الفني.
- `wifi-guardian/`: تطبيق مستقل داخل المستودع، لم يُعدّل ضمن تحويل تطبيق Scool.
