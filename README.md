# تأسيس Kids

تطبيق تعليمي تفاعلي للأطفال في مرحلة التأسيس والصف الأول الابتدائي، بواجهة عربية ودعم اللغة الإنجليزية.

## المواد التعليمية

يضم التطبيق أنشطة مبسطة في اللغة العربية، اللغة الإنجليزية، الحساب، والحساب الذهني، مع أسئلة تفاعلية وانتقال تلقائي بعد الإجابة الصحيحة، وتشجيع صوتي ونتيجة نهائية بالنجوم باسم بسملة.

## التشغيل محليًا

```bash
pnpm install
pnpm dev
```

لتشغيل نسخة الويب التجريبية:

```bash
pnpm dev:metro
```

لفحص المشروع:

```bash
pnpm check
pnpm test
```

## تجربة التطبيق على الهاتف

يمكن تشغيل المشروع عبر Expo Go باستخدام رابط Metro أو QR من واجهة المشروع. إنشاء APK يتم من خلال بيئة البناء الخاصة بالمشروع بعد فتح النسخة المنشورة.

## بنية مهمة

- `app/`: شاشات Expo Router.
- `assets/`: الأيقونات والصوت وخلفية شاشة الدخول.
- `components/`: المكونات المشتركة.
- `todo.md`: سجل المزايا والتعديلات.
- `design.md`: مخطط تجربة المستخدم والتصميم.

## ملاحظات

التطبيق يستخدم بيانات محلية للنسخة الأولية. لا توجد مفاتيح API مطلوبة لتشغيل الأنشطة الحالية.
